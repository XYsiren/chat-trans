# AI 文本转 Word

一个面向学生、教师和科研入门用户的微信小程序：把 AI 对话或 Markdown 文本整理成结构清晰的文档，检查常见公式与内容问题，并导出 Word（`.docx`）。

项目重点是“先识别、可预览、再导出”：用户可以在导出前检查解析结果、修订内容、查看文档提醒并选择适合的排版模板；原文不会因为检查建议而被自动覆盖。

## 功能一览

- **Markdown 结构识别**：标题、段落、引用、有序/无序列表、代码块和表格。
- **LaTeX 公式处理**：识别常见行内与块级公式，规范部分常见 LaTeX 写法，并提供便于阅读的公式预览。
- **文档健康检查**：提示未闭合公式、括号不匹配、标题层级跳跃、缺少一级标题和待补充占位内容等问题；部分问题提供可接受或撤销的修改建议。
- **草稿与编辑**：本地自动保存，支持手动保存到云端；可继续编辑、预览和恢复草稿。
- **模板化 Word 导出**：支持课程作业、实验报告和学术笔记模板，可配置封面与公式编号。
- **公式导出兼容**：Windows/macOS 微信端可请求 Word 原生可编辑公式；手机端使用兼容文本，并在生成前提示差异。
- **反馈与匿名运行指标**：反馈和使用事件通过云函数提交，不采集文档正文作为运行指标。

## 技术栈

- 微信小程序原生框架（WXML、WXSS、JavaScript）
- 微信云开发 / 云函数
- `docx`、MathJax、KaTeX 及公式渲染相关依赖
- Node.js 内置 `assert` 测试

## 项目结构

```text
├─ miniprogram/             # 小程序页面、组件、服务和解析工具
│  ├─ pages/                # 草稿、编辑、模板、导出结果、反馈等页面
│  ├─ components/           # 文档块、问题卡片、模板卡片等组件
│  ├─ services/             # 草稿、文档、指标服务
│  └─ utils/                # Markdown/公式解析、健康检查等
├─ cloudfunctions/          # 云端草稿、审校、Word 导出、反馈和指标函数
├─ tests/                   # 公式解析回归测试和指标测试
├─ docs/                    # 开发、设计、运维和测量说明
└─ project.config.json      # 微信开发者工具项目配置
```

## 当前能力说明

- 小程序端公式预览以可读文本为主，不等同于完整的 TeX 排版。
- 手机端导出的公式为兼容文本；需要独立、可编辑公式时，请使用 Windows 或 macOS 微信端，并在实际 Word/WPS 环境中确认效果。
- 模板的必填章节检查属于导出前提醒，用户仍可根据实际需要决定是否继续。
