# 文档助手

微信小程序：将 Markdown、代码与 LaTeX 内容整理为可检查、可保存并导出 Word 的文档。

## 已实现的流程

1. 我的文档：新建、打开和删除本地草稿。
2. 编辑文档：输入内容，800ms 防抖保存至本地。
3. 识别与预览：识别标题、段落、列表、引用、代码块和块级 LaTeX 公式。
4. 内容检查：检查公式边界/括号、标题层级、占位文本和实验报告必填章节。
5. 选择版式：课程作业、实验报告、学术笔记，以及封面和公式编号选项。
6. 导出：调用 `generateWord` 云函数生成 `.docx`，失败时保留草稿并支持重试。

## 云函数

在微信开发者工具中分别上传并部署：

- `documentParse`：按 OpenID 隔离的草稿云端保存。
- `aiReview`：受限的公式审校接口骨架；接入模型时仅在该函数中配置 API Key 与 Schema 校验。
- `generateWord`：将确认后的结构化块生成 Word 文件。

未部署云函数时，编辑、识别、检查和本地草稿仍然可用；导出页会给出可重试提示。
